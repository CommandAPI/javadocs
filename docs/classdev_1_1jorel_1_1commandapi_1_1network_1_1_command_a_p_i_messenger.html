Detailed Description

Handles sending and receiving CommandAPIPackets between instances of the CommandAPI plugin on different servers.

This class should be extended on each platform to hook into its specific plugin-messaging scheme.

Parameters
<InputChannel>The type of objects that might send a packet to this plugin
<OutputChannel>The type of objects this plugin might send messages to

This is determined by the value in the SetVersionPacket sent by this connection, or 0 if they never sent that packet.
